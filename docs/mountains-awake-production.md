# 《山河醒 / MOUNTAINS AWAKE》制作简报

原创中国风与交响流行纯音乐，96 BPM、4/4，D 小调五声旋律（D / F / G / A / C），48 小节。音乐主体 120 秒，完整版另保留 3.6 秒尾音。定稿参数：移调 0、seed 261013。

## 旋律与结构

八小节副歌以 D–F–G–A 的上行为识别主题，第二句回答，末句回落。主歌由低音区二胡说出稀疏轮廓，笛子在句尾回应；第一副歌首次给出完整主题。最终副歌前八小节重现主题，后八小节继续向高音 D 发展。桥段卸去电子鼓与低音，末尾落回 D。

和声每两小节前进：Dm / Bbmaj7 / Fadd9 / Cadd9。五声主旋律与流行和声分工：旋律保留民族风格，和声允许 Bb、E 等色彩音。最后四小节持续回到 Dm，收束整个旅程。

| 段落 | 小节 | 时间 | 表达 |
| --- | ---: | --- | --- |
| 云开 | 1–4 | 0–10 s | 筝声引子、低强度锣、少量笛声 |
| 沿山而行 | 5–12 | 10–30 s | 二胡主歌、笛声回应、轻流行鼓与低音 |
| 风向高处 | 13–16 | 30–40 s | 笛声上行、筝与深鼓渐密 |
| 山河醒 | 17–24 | 40–60 s | 完整副歌、弦乐与铜管、深鼓和流行鼓组 |
| 一川月色 | 25–28 | 60–70 s | 无节奏组桥段、二胡与冻结筝音 |
| 万象向光 | 29–44 | 70–110 s | 主题回归，再展开高音区变奏 |
| 余响入山 | 45–48 | 110–120 s | 淡出配器、D 落点 |

hook / loop 均从完整乐谱第 17–24 小节提取，分别为 21.6 秒（含 1.6 秒尾音）和 20 秒。短版独立离线渲染；loop 预先渲染三轮，取第三轮以保留跨轮空间尾音，立体声边缘做短淡化。

## 新的声音

新增 `cinematic-guofeng` 制作风格，使用独立编曲器及音源，不把旧风格只改名称。

- **筝声**：模态合成的拨弦泛音、短指甲触弦噪声和迟发按弦音高变化。
- **笛声**：带膜感的谐波波形、气息、轻滑入与延后振音。
- **二胡**：擦弦谐波、低强度弓噪和滑音，主歌比副歌更稀疏。
- **宏大层次**：立体声弦乐与柔铜管，深鼓在关键下拍代替底鼓，锣标记转段。
- **钟玉颗粒**：冻结的筝泛音与不谐和青铜频谱，九个错位软颗粒拼成确定性 PCM，作为引子、桥段和副歌弱拍的闪光。
- **流行元素**：现代 kick / clap / hat、切分电子低音与轻 ducking；低频居中，弦乐高通让出低音空间。

民族乐器为原创、风格化的合成音色，未使用真人演奏采样、歌手录音或外部歌曲片段。互联网资料页因自动审批服务限流未能打开，本次没有将未读取的网络资料作为制作证据。

## 成品与检查

Git 可追踪的三版 MP3 位于 `releases/mountains-awake/`，raw PCM16 WAV 与详细渲染报告位于 `artifacts/audio/mountains-awake-v1/`。MP3 为 320 kbps、44.1 kHz、立体声；两遍响度母带目标沿用项目 −14 LUFS / −1.5 dBTP / LRA 9，实际编码后测量见 release manifest。WAV 保留引擎原始电平，不能把它的统计当成 MP3 母带结果。

| 定稿 MP3 | 解码时长 | 实测响度 | 实测 true peak |
| --- | ---: | ---: | ---: |
| full | 123.600 s | −13.76 LUFS | −1.47 dBTP |
| hook | 21.600 s | −14.12 LUFS | −1.49 dBTP |
| loop | 20.000 s | −14.13 LUFS | −1.49 dBTP |

三个文件解码后均为有限数、无满刻度削波，时长与渲染内容一致。完整版首副歌比桥段高 8.59 dB RMS，最终副歌比桥段高 8.09 dB RMS；合为单声道时整体 RMS 变化约 −0.18 dB。33 项测试与生产构建通过；最终三首曲目的浏览器检查通过。旧曲重复渲染检查曾出现一次已有的偶发最大差值，复查通过，检查阈值未调整。

`npm test` 覆盖乐谱边界、五声旋律、真实裁切、旋律发展、seed 与转调。`npm run build` 检查生产构建。`npm run test:browser` 同时检查旧曲与新风格：八种新增音色独立发声、相同 seed PCM 误差、极限音高/速度、循环边缘、上下文释放、播放进度、WAV 下载及手机布局。最终 MP3 再解码检查时长、非有限数、削波、立体声和段落能量。

自动检查不等于人工耳听；本次未进行人工耳听。未对听感作真人试听背书。

## 复现

```bash
npm run render -- --track mountains-awake --seed 261013 --format both --out artifacts/audio/mountains-awake-local
npm run test:browser
```

试听台可用 `/?track=mountains-awake&version=full` 打开完整版。曲目定义为 `src/tracks/mountains-awake.ts`；独立编曲与音源分别为 `src/music/arrangements/cinematic-guofeng.ts` 和 `src/engine/cinematic-guofeng.ts`。
