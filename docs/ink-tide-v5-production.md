# 《墨潮》第五版：围绕一句旋律重新编曲

第五版针对“乱糟糟、不好听”的反馈重写主题与伴奏，方向转为抒情原声配乐。定稿参数为 **92 BPM / D 大调和声、D 大调五声旋律 / 移调 0 / seed 261014**。完整版为 2 + 8 + 8 + 4 + 16 + 2 = 40 小节，约 5.22 秒进入主段；hook / loop 取完整版第 3–10 小节。full / hook 分别保留 2.8 / 1.4 秒尾音，loop 不加尾音。

本页的旋律与配器说明来自读谱和制作判断，电平来自音频测量；本版未进行人工耳听。轨道数、相加精度和自动检查不能证明作品好听。

## 旋律、拍位与段落

八小节主题有 21 个音，以 D–E–F♯、E–F♯–D 的两小节动机为开头，主要使用长音与半拍网格。长笛是唯一领奏，伴奏没有独立高弦对位或多组错开的琶音。钢琴左手和声壳延续，右手按四分音符演奏同一种分解形态；轻段和桥段减少为一三拍。

主段前四小节由长笛、钢琴、根音低音、底鼓和刷鼓组成，第五小节开始加入小提琴组长和声与大提琴支撑。弦乐每两小节起音，保持共同音；低音与底鼓都落在一三拍，刷鼓在二四拍。轻段降低伴奏活动和能量，四小节桥段撤去低音、鼓与大提琴，只保留主题、钢琴和长弦。

最终段前八小节重述主题，后八小节发展旋律并加入轻沙锤。筒鼓只在最终段最后一小节末出现一次，镲片只在最终段入口出现一次。竖琴只用于前奏、桥段末尾和尾声。八小节句尾的钢琴 A3 回应在该小节起点后 3.25 拍起音；长笛最后一音在起点后 2.75 拍结束，其 105 ms 释放段约在起点后 2.91 拍结束。这里留出的是主奏干声与释放段的间隙，空间尾音仍可能延续。

和声每两小节变化：Dadd9 → Bm7 → Gmaj7 → Aadd9，钢琴和弦采用相邻音区与共同音，低音演奏实际根音。旋律的五声音阶限制不适用于全部和声音。

## 轨道职责

工程配置 12 条独立轨道，hook 实际有 8 条发声；竖琴、沙锤、筒鼓、镲片在该段休止。轨道出现数不等于同时演奏数，也不作为听感评价。

| 轨道 | 音源 | 当前职责 |
| --- | --- | --- |
| flute-theme | 实录长笛 | 唯一主旋律，中央 |
| piano-harmony | 实录钢琴 | 单一活动伴奏，略偏左 |
| piano-upper | 实录钢琴 | 八小节句尾单音回应 |
| harp-turn | 实录竖琴 | 少量段落衔接，略偏右 |
| violin-bed | 实录小提琴组 | 两小节长和声，略偏左 |
| cello-floor | 实录大提琴组 | 长音支撑，略偏右 |
| round-bass | 合成低音 | 一三拍根音，中央 |
| soft-kick | 合成底鼓 | 一三拍稳定脉搏，中央 |
| brush-snare | 合成刷鼓 | 二四拍轻节奏 |
| woven-shaker | 合成沙锤 | 最终段后八小节的轻八分层 |
| tom-fill | 合成筒鼓 | 最终段末的一次收束 |
| cymbal-air | 合成镲片 | 最终段入口的一次展开 |

分轨预览用于检查实际主奏与伴奏电平，随后调整采样总增益和轨道增益。持续段 RMS 用于避免原录音强弱差异造成部分音高过低；这是一项能量校准，不能判断各声部是否悦耳、空间是否自然或配器是否清楚。

## 采样来源与边界

钢琴沿用 **Alexander Holm / Salamander Grand Piano v3** 的 13 份本地录音，CC BY 3.0，保留[作者与处理说明](../public/audio/salamander/ATTRIBUTION.md)。新增长笛、小提琴组、大提琴组和竖琴采用 **VSCO 2 Community Edition** 的 25 份本地录音：长笛 6 份、小提琴组 7 份、大提琴组 5 份、竖琴 7 份。

VSCO 录音作者为 Sam Gossner / Versilian Studios 与 Simon Dalzell / Ivy Audio，切样为 Elan Hickler / Soundemote。来源固定为 `sgossner/VSCO-2-CE` commit `440300901dfe9275fd84e0b7763af1f8443ae62e`；官方项目和仓库 LICENSE 均标明 **CC0 1.0 Universal**。[署名与处理说明](../public/audio/vsco/ATTRIBUTION.md)和[采样 manifest](../public/audio/vsco/sample-manifest.json)保存原始文件、MIDI 映射、裁切帧、时长、电平与 SHA-256。

原 WAV 取左声道、裁去首尾静音并保留起音和自然尾声，再编码为 128 kbps / 44.1 kHz / mono MP3。源文件没有峰值或响度归一化、去噪、均衡、人工混响或音高校正。长笛、小提琴组、大提琴组的原文件名比科学音高低一八度，竖琴遵循科学音高，因此按源 SFZ 的 `pitch_keycenter` 与录音频率交叉核对后再命名本地文件。

播放器按最近 MIDI 采样变速，保留原录音的呼吸、弓弦与自然波动；不另加每音重新启动的人工振音，也不制作长音循环。每个音高只有一条录音，velocity 调整播放增益；本项目没有完整多力度层、round robin 或连奏采样。持续段电平补偿以起点后 0.4–2.4 秒 RMS 计算，参照当前音域的中位值，限制为 0.5–2 倍，并与音色整体增益分开保存。该补偿不改写采样 PCM，也不增加真实演奏层。

## 渲染、试听与分轨

`src/music/ink-tide-mix.ts` 根据实际段落边界生成自动化，裁切版使用原曲在边界的插值电平。`MusicalEvent.trackId` 将声部身份与音色分开；`renderTrack(track, options, selection)` 保留 `soloTrackIds`、`muteTrackIds` 和 `processing: 'raw'`。每轨与每事件的噪声均独立 seeded，底鼓静音时低音 ducking 仍从原乐谱底鼓驱动，避免改变剩余分轨。

钢琴与四类原声采样在离线渲染前加载并解码，四类原声音源库只在全部成功后发布；失败清理 pending，后续调用可以重试。渲染任务串行执行，自有节点完成或失败后释放，恢复原 Tone 上下文。

网页 `/?track=ink-tide&version=hook` 可独听一轨、移除一轨和导出当前选择。切换版本或轨道选择清除旧缓存；当前版本无事件的轨道标为“此段休止”并禁用，改变版本后若原选择休止则返回完整混音。段落矩阵展示各轨何时出现。

```bash
npm run render -- --track ink-tide --seed 261014 --format both --out artifacts/audio/ink-tide-v5-local
npm run render:stems -- --version hook --seed 261014 --out artifacts/audio/ink-tide-v5-local-stems
```

分轨 CLI 要求新目录，保存 12 条 PCM16 WAV、raw mix 与浮点相加测量。所有 WAV 从 time 0 对齐，以 unity gain 导入 DAW；其中休止轨道为静音文件。分轨保留轨道滤波、声像、空间发送、自动化和原始电平，不逐轨 normalize，不应用最终去 DC、边缘淡化、峰值修整或响度母带。浮点相加还原 raw 混音；PCM16 量化会增加误差，最终母带 MP3 是另外的处理阶段。

## 交付与验证记录

成品目录为 `releases/ink-tide-v5/`，包含 `ink-tide-{full,hook,loop}-92bpm-t0-s261014.mp3`、实测 manifest 和来源记录。MP3 为 320 kbps / 44.1 kHz / stereo，最终编码后测量如下；文件 SHA-256、解码帧数与源码指纹以 release manifest 为准。

| 版本 | 解码内容时长 | Integrated LUFS | True peak dBTP |
| --- | ---: | ---: | ---: |
| full | 107.147823 s | −14.00 | −1.58 |
| hook | 22.269546 s | −14.00 | −1.88 |
| loop | 20.869569 s | −14.00 | −1.91 |

解码音频没有非有限值或满幅样本，单声道合并 RMS 变化约 −0.023 dB。hook 原电平分轨的全段 RMS 为长笛 −25.14 dBFS、钢琴 −33.79 dBFS；只在后四小节发声的弦乐与大提琴，在该后半段 RMS 分别为 −35.27 / −41.10 dBFS。这些数值描述测量窗口内的能量，不能直接当作感知响度或配器听感。最终分轨浮点相加最大误差约 `6.3024e−8`、差值 RMS `< 1e−8`，不包含 WAV 量化误差。

`npm run check` 的 49 项单元检查及构建通过。单元检查覆盖谱面拍位、裁切、长和声、句尾留白、混音自动化和参数边界；浏览器检查入口 `npm run test:browser` 覆盖原声采样缺失与重试、独听和移除、休止轨道、分轨相加、同 seed 复现、循环、播放器和导出。复现与分轨相加保持最大差 `< 1/65536`、差值 RMS `< 1e-6` 的阈值。

首次串行浏览器运行在旧曲《山河醒》的同 seed 检查停止：最大差约 `9.986758e−5`，差值 RMS 约 `4.066e−7`，最大差超出原阈值。旧音源与阈值均未修改，随后独立复查通过，最大差约 `3.57628e−7`、差值 RMS 约 `1.30433e−8`；记录保留初次失败，不推断波动原因。《余温》《风起时》的浏览器检查通过；《墨潮》目标浏览器检查也通过，其同 seed 最大差约 `1.1920929e−7`、差值 RMS 约 `8.57149e−9`，包括四类采样缺失与重试、25 份单声道采样、播放器和导出。

多轨浏览器检查最终通过，覆盖 12 条分轨（含当前段落休止轨道）、solo / mute、全静音、休止选项、缓存刷新和当前选择导出。浏览器分轨相加最大误差约 `6.8399544e−8`、差值 RMS 约 `4.8920942e−9`；移除主奏与完整混音减去主奏的最大误差约 `6.7055e−8`、差值 RMS 约 `5.0128e−9`。重复 raw 分轨差值和全静音结果均为 0。所有必需目标经上述复查后完成，未宣称首次整套浏览器运行直接通过；各脚本结果与音频测量由 release manifest 留档。
