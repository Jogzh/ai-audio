# 《墨潮 / Ink Tide》：参考调研与制作记录

查阅与制作日期：2026-10-14。用户提供的具体参考是 [ZHENLOE《We Never》](https://music.163.com/song?id=3397959121)，因此本次从这首歌分析推进速度与段落能量，而不把“vibe 知识大赏”当作一个已核验的榜单或音乐流派。

## 实际调研

网易云单曲页确认曲名、作者与专辑均对应上述链接。公开元数据与官方公开试听 MP3 的时长为 **168.293 秒**，试听文件为 128 kbps / 48 kHz / 立体声。原曲只用于本地分析，没有纳入本仓库音频、混音或成品。

客观测量使用 FFmpeg 与 NumPy。多频段起音自相关、8/16 拍长周期插值及频率投影交叉估计，主要节奏周期约 **125.4–125.6 BPM**；约 83 BPM 的候选为 3:2 周期歧义，不能将算法结果说成官方 BPM。频谱和包络显示：0–46 秒较暗，约 42 秒开始变亮，46–92 秒展开，92–104 秒能量回收，104–152 秒再次展开，152 秒后淡出。这是按信号变化划分的段落，不是耳听确认的主歌或副歌。

全曲 20–200 Hz 占线性谱能量约 72.2%；这个比例不等于人耳响度，也不用作新曲 EQ 目标。峰值色度对 D minor / F major 的相关度约 0.722 / 0.660，只能提供低置信的调性色彩线索。参考 MP3 实测 -10.68 LUFS、LRA 3.40 LU、+1.17 dBTP，解码过冲不证明原始母带削波。

网页播放操作超时，后续改用官方公开试听文件做上述信号分析。没有进行人工耳听，没有通过这些数据识别或确认参考曲的具体乐器，也没有核验当日抖音热度。详细本地分析与脚本在 `artifacts/audio/ink-tide-research/`。

## 原创设计

《墨潮》为独立创作的 **124 BPM / D 小调五声 / 国风旋律 House**。参考借鉴落实到接近的推进速度、亮度展开与中段回收；旋律、和声、节奏和音源均单独设计，没有使用参考录音或重写其旋律。

- 两小节核心短句为 D–F–A 的提问与 G–F–D 的回应，八小节内随和声改变尾句。主题每小节三个音，主奏写定音符不重叠。
- 木质琴弦主奏，箫只在留白中回应；最终段的四个小节改由软电子拨弦接棒，后八小节展开独立变奏。玉磬只在少数句尾出现。
- Dm9 → Bbmaj7 → Fadd9 → Csus2，每和弦两小节。单层三声部和声托底，短电钢琴双音填空；低音不重复叠加 sub。
- 主段四分底鼓保持稳定，短低音在反拍进入，木边击标记二四拍，沙锤轻微延后反拍。seed 只改变力度和合成触感，不改写音高或重拍。
- 新音源采用多拨弦位置、多力度频谱与轻按弦，箫分离谐波和气息、长音后半段才出现颤音。有限短暗混响、有限前向回声、居中低频与轻 ducking 控制掩蔽。
- 在真实 PCM 校准中发现电子主音比琴声过轻，提升并调整其包络，使后段交接保持前景旋律；修复 Tone BufferSource 的按弦兼容问题，使用 playbackRate 调度。
- 重复渲染发现原生压缩器使同 seed 最大波形差达到 `3.67e-5`，超过项目阈值。改为固定增益后最大差降至 `2.38e-7`、差值 RMS 为 `1.69e-8`，保留原有严格阈值；峰值整理和最终响度母带继续由现有后处理负责。

这些是具体制作选择，不是“自动证明好听”的指标。所有国风音色均为风格化原创合成，并非真人乐器录音。

## 结构与导出

40 小节：**2 引子 + 8 主题 + 8 轻主歌 + 4 无鼓桥 + 16 回归与变奏 + 2 尾声**。第一拍出现琴声，主段在约 **3.871 秒**进入。主体音乐 77.419 秒，完整版保留 2.8 秒尾音。hook / loop 精确取全曲第 3–10 小节的乐谱再渲染；hook 加 1.4 秒尾音，loop 预热三轮后取第三轮，不添加时长。

定稿参数为 124 BPM / 移调 0 / seed **261014**。MP3 采用 320 kbps / 44.1 kHz / 立体声，母带目标 -14 LUFS / -1.5 dBTP / LRA 9；目标是项目选择，最终文件实测见 release manifest。WAV 默认保留原始 PCM16。

```bash
npm run render -- --track ink-tide --seed 261014 --format both --out artifacts/audio/ink-tide-local
npm run check
npm run test:browser
```

在试听台打开 `/?track=ink-tide&version=hook`，并把 seed 设为 261014。音源、曲谱与编曲分别位于 `src/engine/ink-tide.ts`、`src/tracks/ink-tide.ts` 和 `src/music/arrangements/ink-tide.ts`。

## 验证边界

自动检查涵盖主奏与应答留白、真实短版裁切、参数及旋律配置边界、seed 与移调、实际浏览器音源、相同参数 PCM 复现、单声道兼容、循环边缘、上下文清理、播放器与 WAV 下载。成品再解码检查响度、真峰、有限采样和单声道电平。

最终 38 项单元/FFmpeg 测试及生产构建通过；旧曲浏览器检查通过，新曲在上述压缩器修复后专项检查通过。三版最终 MP3 解码帧数与源 PCM 一致，非有限采样与满刻度采样均为 0。

| 版本 | 解码时长 | 实测 LUFS | 实测 dBTP |
| --- | ---: | ---: | ---: |
| full | 80.219 s | -14.00 | -1.46 |
| hook | 16.884 s | -14.09 | -1.49 |
| loop | 15.484 s | -14.12 | -1.50 |

三版单声道 RMS 损失约 0.02 dB；桥段比轻主歌低 3.14 dB、比最终主段低 5.94 dB；电子主音接棒处两小节 RMS 变化小于 0.22 dB。循环 MP3 首尾单采样最大跳幅约 -70.46 dBFS，但句尾休止与新一拍仍有节奏能量变化，播放器也需要正确处理 MP3 的编码延迟信息。完整实测保存在 `releases/ink-tide/manifest.json` 与 `decoded-check.json`，原始 WAV 和详细母带报告在 `artifacts/audio/ink-tide-final-v2/`。

没有进行人工耳听评审。测量可以排查静音、严重电平问题与接口错误，不能替代对旋律、音色与循环听感的实际判断。
