# 《墨潮 / Ink Tide》第三版：钢琴与弦乐

> 本文的成品音频路径指本地文件；MP3/WAV 不随 Git 分发，实测 manifest 与制作记录保留。新克隆请用试听台或导出命令重新生成。

制作日期：2026-10-14。用户再次反馈第二版不好听，并明确允许自由发挥、不再按照原先的箫鼓偏好制作。本版保留《墨潮》名称与 `ink-tide` 曲目 ID，重新写成 **96 BPM / E 自然小调 / 钢琴电影配乐**。核心变化是使用钢琴实录采样承载新旋律，让弦乐与轻柔碎拍作为背景推进，而不是继续扩展第二版的箫鼓音色。

## 参考与判断依据

最初参考为用户提供的 [ZHENLOE《We Never》](https://music.163.com/song?id=3397959121)。其公开试听音频的客观分析方法及边界保留在[第一版制作记录](ink-tide-production.md)，本轮没有把该参考认定为当前抖音热度已核验的作品。第三版旋律重新独立写作，参考录音及其旋律没有进入成品。

本版根据用户撤去配器约束的反馈重新决定速度、调性、主题与配器。钢琴、弦乐及节奏的源码可以说明制作方式，客观测量可以检查静音、削波、响度和接缝，自动测试可以验证乐谱与渲染行为；这些均不能证明音乐好听。本轮没有进行人工耳听评审。

## 旋律与编曲

引子由钢琴从第一拍进入，在两小节中依次提出 E、G、B。主段以 B–G–E 下行短句展开，随后以 F♯–G–B 回答；八小节主题以 E 收束。主题主要在 E4–D5 区间，最终段后半向 E5 发展。较长的句尾与休止给钢琴尾音留出空间，少量低声部应答出现在主题的书面空隙。

和声围绕 Em7、Cmaj7、Dadd9、G/D、Bm7 和 Em(add9) 展开。钢琴用稀疏双音或短和弦补充和声，弦乐缓慢起音并承接持续音；低音与底鼓在关键拍位共同推进，短促的打击与少量高频短击形成轻柔碎拍。最终段增加少量节奏细节和旋律发展，桥段撤去节奏声部，尾声回到安静的 E 小调和声。

当前六类声部为 `piano`、`strings`、`bass`、`kick`、`perc`、`hat`。第二版的箫与中国鼓模块没有进入第三版乐谱。前两版成品与制作文档保留，不将历史成品替换成本版音频。

## 钢琴采样、许可与音源实现

钢琴录音来自 **Alexander Holm 的 Salamander Grand Piano v3**，许可为 **Creative Commons Attribution 3.0 Unported（CC BY 3.0）**。作者与许可已从 [sfzinstruments 原音源说明](https://github.com/sfzinstruments/SalamanderGrandPiano/blob/master/README.md)核实，原集合见 [Internet Archive](https://archive.org/details/SalamanderGrandPianoV3)，本项目采用的 MP3 分发见 [Tone.js audio](https://github.com/Tonejs/audio/tree/master/salamander)。许可文本见 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/legalcode)。

13 个 MP3 录音随仓库保存在 `public/audio/salamander/`。这些文件从 Tone.js 分发复制，采样文件本身未修改；项目服务提供静态文件，浏览器和离线渲染从项目内加载，不需要播放时向远端请求音源。完整作者、来源与处理说明保存在[静态目录署名文件](../public/audio/salamander/ATTRIBUTION.md)。软件 MIT 许可与钢琴采样许可分别适用。

当前实现为每个采样音高使用一份录音，邻近音高通过播放速率转换；力度通过播放增益与低通滤波改变响度和亮度。初次分轨测量发现 AB 双麦克风录音在单声道折叠时，钢琴主题损失约 2.01 dB。因此播放 bank 选取每份原录音的左麦克风声道，之后加入轻微声像与空间，不把两只麦克风平均相加；同时降低低音和底鼓并校准琴声，使主题在单声道中保持稳定。该选择来自客观分轨证据，不是耳听结论。原 Salamander 集合包含 16 个力度层，本项目没有引入这些完整层级，因此不将增益或滤波变化描述为真实的多力度录音采样。进入混音后，录音还经过音高转换、包络、滤波与空间处理，并与独立旋律、合成伴奏混合。

弦乐、低音和打击声由代码合成，没有使用弦乐或鼓的外部实录采样。音源使用固定增益和有限空间，保留钢琴音头与自然衰减；少量低音避让发生在底鼓起音处，钢琴旋律保持完整包络。样本加载先于 Offline 任务，渲染仍独立持有并释放自己的节点和声源，结束或失败后恢复原上下文。

## 结构与交付参数

40 小节、4/4 拍，结构为 **2 + 8 + 8 + 4 + 16 + 2**。96 BPM 下主体音乐恰为 **100 秒**，主段在第 3 小节、约 **5 秒**进入。hook / loop 引用完整乐谱实际第 3–10 小节，再独立渲染；loop 按项目规则渲染三轮并截取第三轮，保留跨轮空间尾音。

| 段落 | 小节数 | 编曲作用 |
| --- | ---: | --- |
| 夜窗 | 2 | 钢琴先提出主题，少量和弦与弦乐进入 |
| 微光 | 8 | 主题与轻柔节奏完整展开 |
| 雨后街灯 | 8 | 回收强度、减少和声与节奏细节 |
| 无声的片刻 | 4 | 无鼓桥段，钢琴低区长句留白 |
| 潮向远方 | 16 | 主题回归，后八小节向高处发展 |
| 灯还亮着 | 2 | 钢琴与弦乐收束 |

导出参数为 **96 BPM / 移调 0 / seed 261014**，MP3 为 320 kbps / 44.1 kHz / 立体声。下表为最终 MP3 解码内容时长；详细测量数据见[第三版 manifest](../releases/ink-tide-v3/manifest.json)。

| 版本 | 内容 | 解码内容时长 | MP3 |
| --- | --- | ---: | --- |
| full | 40 小节 + 2.8 秒尾音 | 102.8 s | 完整版（`../releases/ink-tide-v3/ink-tide-full-96bpm-t0-s261014.mp3`） |
| hook | 8 小节 + 1.4 秒尾音 | 21.399977 s | 精华片段（`../releases/ink-tide-v3/ink-tide-hook-96bpm-t0-s261014.mp3`） |
| loop | 8 小节，三轮预热后取第三轮 | 20 s | 循环配乐（`../releases/ink-tide-v3/ink-tide-loop-96bpm-t0-s261014.mp3`） |

默认 MP3 母带目标为 -14 LUFS / -1.5 dBTP / LRA 9，是项目制作选择，不是平台官方要求；源动态和有损编码可能使最终值偏离目标。原始 WAV 默认保留引擎 PCM16。MP3 的无缝循环仍取决于播放器是否正确处理编码延迟与填充信息。

```bash
npm run render -- --track ink-tide --seed 261014 --format both --out artifacts/audio/ink-tide-v3-local
npm run check
npm run test:browser
```

试听台 `/?track=ink-tide&version=hook` 使用第三版，seed 设为 261014。曲谱位于 `src/tracks/ink-tide.ts`，编曲位于 `src/music/arrangements/ink-tide.ts`，音源位于 `src/engine/ink-tide.ts`，采样加载器位于 `src/engine/piano-samples.ts`。

前两版保留供试听比较：[第一版制作记录](ink-tide-production.md)、[第二版制作记录](ink-tide-v2-production.md)、第一版 hook（`../releases/ink-tide/ink-tide-hook-124bpm-t0-s261014.mp3`）、第二版 hook（`../releases/ink-tide-v2/ink-tide-hook-102bpm-t0-s261014.mp3`）。前两版的测试结果不用于宣称第三版已通过。

本次 FFmpeg 母带报告显示实际使用动态响度处理，以同时整理实录钢琴的音头峰值与整体响度；不能写成仅增加固定增益。loop 首尾单采样最大跳幅约 **-82.56 dBFS**。桥段解码 RMS 较轻段低 **2.829 dB**、较最终段低 **4.934 dB**；这些是对应窗口的能量差。

最终分轨直接使用原始音源幅度，没有分别做峰值或响度归一化。钢琴主题主体 RMS 为 **-31.74 dBFS**，低音为 **-36.59 dBFS**，差约 **4.85 dB**；钢琴主题单声道损失约 **0.007 dB**。分轨分别渲染会改变声部间随机数调用顺序，因此用于增益和兼容性比较，并非能逐采样相加的精确 stems。它们也不能证明人耳的主次判断或听感质量。完整客观记录随 release manifest 保存，原始 WAV、分轨与母带报告位于 `artifacts/audio/ink-tide-v3*`。

乐谱、渲染及电平检查各自只证明其检查覆盖的条件。最终交付包含可播放音频，实际听感由试听评估，不能把自动检查通过写成“好听已验证”。
