# 折返频率 / Switchback

制作日期：2026-10-16。**136 BPM / F minor / 80 小节 / 142.58 秒**。沿用《夜航线》的 DJ 主导、人声短暂插入方向，重新写作空心 FM 动机、滚动低音、切分变奏、金属回答和 80 小节编排。

本次人声为新写的中文合成短句，原生 24 kHz 单声道；用本地 Kokoro `zm_010` 生成，再进行实际变速、移调、滤波、声码、切片和停带处理。没有使用《夜航线》的录音或唱句。`zm_010` 声包曾用于项目较早的作品，本次没有复用旧口号或旧音频。

中段的三个声线状态是实际 DSP 处理：

1. **低调电台呼叫**：“让频率接管”降 5 半音，播放速度为原来的 0.86 倍；“别回头”同样降 5 半音、0.92 倍。加 180 Hz 高通、4.4 kHz 低通与适量饱和。
2. **升调碎拍回应**：整句升 7 半音、1.28 倍速；后续“现在”从原调逐步升至 +12 半音，并缩短切片与间距，最后一个片段速度为 1.5 倍。
3. **停带与声码**：“走”连续降低采样播放速率，从约 1.55 倍降至 0.10 倍，约 0.99 秒；第二段句尾另用八频带声码器及 F3 载波。

反向人声和延迟主要进入人声效果总线。直接人声区间合计 **9.33 秒，占文件 6.55%**；这是包括切片、声码、停带在内的区间测量，不包含全部效果尾音。主旋律由新写的器乐动机承担。

低频分为约 47 Hz 的底鼓、mono rumble 和 F1 起的贝斯。它们按底鼓触发侧链；第二次 Drop 前的一拍对鼓、贝斯、主音及生成后的 rumble 一起衰减，防止湿低频填平留白。

## 复现

使用现有 Python 3.11 环境，DSP 依赖为 `scripts/requirements-dj.txt`，另需 FFmpeg / FFprobe。已经准备好 `source/` 时：

```bash
artifacts/dj-tools/bin/python scripts/switchback.py all
```

`render` 和 `master` 可分开运行，预设位于 `scripts/presets/switchback.json`。默认输出为本地 `artifacts/audio/switchback/`；保存不同修订时使用新 `--out` 目录。制作脚本会覆盖指定目录中的已有渲染文件。

重新生成干声需本地模型与 voice 文件，以及 `torch`、`kokoro`、`misaki[zh]`、`numpy`、`soundfile`；现有环境从 `artifacts/vocal-tools/lib/python3.11/site-packages` 加载。生成器拒绝覆盖已有干声：

```bash
artifacts/dj-tools/bin/python scripts/generate_switchback_voice.py \
  --out artifacts/audio/switchback/source-new
```

如改用新干声目录，需同步更新预设的 `voiceDirectory`。移调先用 `asetrate + aresample` 改变基频与共振峰，再用 `atempo` 独立调整速度；缓存键同时包含输入 PCM、移调和速度。
