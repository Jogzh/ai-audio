# 《墨潮》第四版：多轨编曲与独立混音

本版针对曲子单调、声部不足的反馈，重写旋律、编曲、音源和路由。96 BPM / E Aeolian，seed 261014，移调 0。完整版结构仍为 2 + 8 + 8 + 4 + 16 + 2 = 40 小节，5 秒进入主段；full / hook / loop 的 PCM 时长分别为 102.8 / 21.399977 / 20 秒。

## 实际编曲

主题从 B–D–E 上行开始，八小节写有 26 个音，留出气流应答的位置。后半最终段改写主题、增加高弦对位和大提琴行进，吉他由疏朗织纹展开为八分音符。共 1120 个事件，前奏 / 主段 / 轻段 / 桥段 / 最终段 / 尾声分别有 6 / 16 / 16 / 8 / 16 / 9 条轨道出现；这是整个段落的出现数，并非每拍叠加数量。桥段撤去节奏低音和鼓。

| 轨道 | 职责 | 音区与空间 |
| --- | --- | --- |
| piano-theme | 钢琴主题 | 较高区，靠中央、少量短空间 |
| breath-reply | 气流应答 | 只占主题乐谱休止，右侧 |
| piano-harmony | 钢琴和声壳 | 低区双音，左侧、减少高频 |
| guitar-weave | 木吉他琶音 | 错开钢琴拍位，右侧 |
| plucked-light | 拨弦点缀 | 高区小手势，左侧 |
| violin-line | 高弦对位 | 中高区长线，末段展开 |
| viola-bed | 中弦和声 | 中区双音，渐入渐出 |
| cello-line | 大提琴行进 | 低中区，长线转移动音 |
| air-pad | 呼吸底色 | 两小节延续，滤掉低频 |
| round-bass | 节奏低音 | 居中，轻微底鼓避让 |

初次实际分轨渲染发现刷鼓、沙锤、闭镲电平过低，随后提高节奏层，同时提高应答、中高弦和拨弦贡献、降低低音比例。该调整依据分轨峰值与 RMS，属于客观能量检查，不是耳听结论。

## 可扩展的代码结构

`src/music/types.ts` 用 `MixTrack` 描述独立声部，`MusicalEvent.trackId` 指向轨道；音色名称不再同时充当轨道身份。`ink-tide-mix.ts` 保存 16 轨电平、声像、滤波、空间发送及逐段音量曲线。短版自动化以原始曲线在裁切边界的插值开始和结束。

本曲自动化配置对应当前 40 小节段落边界；未来改动段落长度时须同步调整混音曲线。短版按乐谱裁切并重新合成，事件随机身份使用裁切后的拍位，部分音色细节可能与 full 对应段不同，不能视为成品波形裁切。

`src/music/mixer.ts` 在创建 Web Audio 节点前校验路由、混音值和自动化顺序。`renderTrack(track, options, selection)` 支持 `soloTrackIds`、`muteTrackIds`、`processing: 'raw'`；默认保留原来的正常导出行为。低音侧链始终从原乐谱底鼓驱动，因此静音底鼓不会改变低音分轨。

`src/engine/ink-tide-voices.ts` 负责发声，`ink-tide.ts` 负责轨道条、线性总线和节点释放。每轨独立噪声池、每事件独立随机身份，共享 room / 三个前向回声也固定 seeded。无原生总线压缩或非线性母线，raw 分轨可相加还原 raw 混音；正常输出的峰值处理和 FFmpeg 响度母带是另一处理阶段。

钢琴沿用 Alexander Holm / Salamander Grand Piano v3 的 13 份本地录音，CC BY 3.0；仍是一音高一录音的近邻变速，并非完整多力度采样。吉他和拨弦是 3 种激励变体的 Karplus–Strong 缓存 PCM；箫与弦是谐波、气流、弓噪及不同包络的合成模型；鼓包含模态主体与滤波噪声。合成乐器名称描述目标音色，不代表实录来源。

## 播放与分轨

网页曲目 `ink-tide` 可单独听一轨、移除一轨、导出当前选择；改变选择会清除旧音频缓存。段落矩阵展示各轨何时演奏。其他曲目的播放入口保持兼容。

```bash
npm run render -- --track ink-tide --seed 261014 --format both --out artifacts/audio/ink-tide-v4-local
npm run render:stems -- --version hook --seed 261014 --out artifacts/audio/ink-tide-v4-local-stems
```

`render:stems` 要求新目录，导出 16 轨 PCM16 WAV、raw mix 和相加测量。所有文件从 time 0 导入 DAW，保持 unity gain；不独立 normalize，不做去 DC / 淡化 / 最终母带。原始 loop 保留实际边缘样本，正常 loop 则沿用三轮取第三轮和约 3 ms 边缘淡化。

## 验证和听感边界

单元检查覆盖乐谱裁切、路由、输入错误、自动化插值、应答留白及移调。真实浏览器检查覆盖 15 种音源、16 轨有效 PCM、分轨相加、solo / mute、同 seed 复现、BPM 与移调极限、单声道合并、播放下载和缓存刷新。MP3 解码检查覆盖有效采样、帧数、循环边界和各段能量；LUFS 与 true peak 为最终编码后实测，详见 release manifest。
