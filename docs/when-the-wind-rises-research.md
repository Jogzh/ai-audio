## 与上一首相比的具体改进

- **真正留白的问答**：八小节主题的第 2、4、6、8 小节在约 2.14 拍结束主句；电钢琴从 2.75 拍接话。答句不与主旋律的写定时值重叠，也不沿用原来的低八度元音叠加。
- **重复后的发展**：最终主段前八小节保留主题，后八小节使用独立写出的变奏，从 A5 推至 B5，再回落。保留辨识度并扩大后半段的情绪范围。
- **桥段减法**：桥段用较低、较长、较少的电钢琴单音，撤去鼓与低音，钢琴伴奏降至每小节一个点；不靠大量噪声堆积制造推进。
- **有呼吸的律动**：采用两小节切分底鼓与错位低音，鼓和低音力度比原模板略轻。贝斯带泛音，底鼓与 sub 仍居中。
- **完整作品与短版一致**：hook / loop 均裁自 full 的第 3–10 小节，保留同一主题、答句、和声与节奏。loop 继续预热三轮、截第三轮，再做约 3 ms 边缘淡化。

和声为 Dmaj9 → Bm7 → Gmaj9 → A6/9，每个和声两小节；结尾回到 D。主段约在 4.21 秒进入，主题从第一拍出现。原有《余温》的乐谱与合成音源保持兼容；旋律发展是曲目级可选数据，不套用到每首歌。

## 复现与验收

定稿参数：114 BPM、移调 0、seed 261013。仅在本地保留的三版 MP3 位于 `releases/when-the-wind-rises/`，[release manifest](../releases/when-the-wind-rises/manifest.json) 保存文件 SHA256、参数、最终测量和源码指纹。本地导出的 WAV 与诊断报告仍保存在 `artifacts/`。导出命令：

```bash
npm run render -- --track when-the-wind-rises --seed 261013 --format both --out artifacts/audio/when-the-wind-rises-v2
```

MP3 采用 320 kbps / 44.1 kHz / 立体声和双遍 loudnorm；WAV 保留引擎原始 PCM16。制作目标仍为 −14 LUFS / −1.5 dBTP / LRA 9。目标不代表最终测量或平台标准，最终文件数据以输出目录的 manifest、母带报告与 decoded-check 为准。

自动检查覆盖配置边界、真实乐谱裁切、应答留白、最终变奏、桥段减法、相同 seed 复现、非静音、参数边界、循环边缘、播放器及最终 MP3 的解码电平与单声道兼容。没有人工耳听评审；作品交付用于用户实际试听。

后续改进应记录用户实际喜欢或不喜欢的时间点，再更改对应旋律、音色或段落，并保留修订间的实测与参数记录。不能仅凭电平、波形或测试通过就断言下一首更好听。
