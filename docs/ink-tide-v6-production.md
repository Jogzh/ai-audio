# 《墨潮》第六版：高潮发展与段落对比

本版针对“高潮有些平淡”继续优化。定稿参数仍为 **92 BPM / D 大调和声、D 大调五声旋律 / 移调 0 / seed 261014**，40 小节，结构 2 + 8 + 8 + 4 + 16 + 2。主要修改完整曲的桥段与最终段，保留清楚的长笛主奏、钢琴脉搏与原声音色。

以下配器分析来自谱面与制作判断，测量来自实际音频。本版尚未人工耳听，能量差和检查通过不能证明高潮悦耳或感人。

## 本次改动

最终段前八小节仍重述原主题；后八小节从 **78.26 秒**开始，以 Gmaj7 → Aadd9 → Dadd9 → Bm7 的两小节和声路径发展。长笛重新写成上行与回落的乐句，高点从原 A5 提至 B5，最后落回 D5，并由尾声的 D 大调接住。旋律维持单音主奏，最长句尾不再塞入钢琴回答。

弦乐与大提琴按实际新和声重新配位：弦乐上移部分外声部，大提琴跟随和声支撑；它们保持两小节长音，钢琴仍使用原来的四分脉搏。低音保持真实根音，底鼓一三拍、刷鼓二四拍。后半段增加的是力度和段落电平，拍位保持一致；轻沙锤仅在最终段后八小节进入。

筒鼓在最终段第八小节末与最后小节末各一次，前者用较高音高引入抬升，后者用较低音高收束。竖琴在最终段第十、十四小节 3.75 拍处各回答一个音；入口晚于主笛谱面结束及其 105 ms 释放段，拨弦尾音仍会延续到下一小节的兼容和声。镲片仍只在最终段入口出现。

桥段撤去鼓与低音，并降低长笛、钢琴与弦乐的段落电平，让随后主题重入有更明显的对比。没有为提升高潮另加连续领奏或多套琶音。

## 回答配置与验证

`TrackDefinition.inkTide.finalResponse` 为最终主题提供独立回答。省略时复用原 `response`，保持旧配置的行为；显式空数组可让高潮长句保留留白。基础主题的 `response` 只需适配基础旋律；最终回答单独匹配 `finalHook`，并检查小节数量、音符边界与是否重叠。只有声明最终旋律时才能配置 `finalResponse`。

本曲最终回答为空，原主题第八小节的 A3 钢琴回答仍在 3.25 拍进入。和声换位同时驱动钢琴、弦乐、大提琴和低音，测试检查这些声部是否实际跟随新和声，避免只改变标签或低音而保留错误弦乐音。

独立路由仍为 12 条；分轨、solo / mute、原电平相加、采样加载重试与同 seed 阈值沿用第五版。源采样、原声采样补偿和乐器播放包络未改，详见[第五版采样与工程说明](ink-tide-v5-production.md)。钢琴使用 Salamander Grand Piano / CC BY 3.0，长笛、弦乐、大提琴、竖琴使用 VSCO 2 CE / CC0；相关署名继续保留。

## 试听与导出

成品位于 `releases/ink-tide-v6/`。`full` 含本次高潮发展；`hook` / `loop` 仍是完整版第 3–10 小节，便于保留开头主段用法，不能用它们判断新高潮。

| 音频 | 内容 | 解码内容时长 |
| --- | --- | ---: |
| full | 40 小节 + 2.8 秒尾音 | 107.147823 s |
| hook | 开头主段八小节 + 1.4 秒尾音 | 22.269546 s |
| loop | 开头主段八小节循环 | 20.869569 s |
| climax | 完整 WAV 从约 73.04 秒至原尾音结束 | 34.104354 s |

高潮试听从完整 WAV 的精确帧 `round(112 × 60 / 92 × 44100)` 裁出，开头加 20 ms 淡入后单独母带为 320 kbps / 44.1 kHz / stereo MP3。它包含抬升前两小节、最后八小节和两小节尾声及原尾音，不是将完整版 MP3 再次有损转码。片段与完整版分别测量 LUFS 和 true peak，不能假定二者波形或电平逐样本一致。

```bash
npm run render -- --track ink-tide --seed 261014 --format both --out artifacts/audio/ink-tide-v6-local
npm run render:stems -- --version full --seed 261014 --out artifacts/audio/ink-tide-v6-full-stems
```

## 客观对比与检查记录

以第五版与第六版正常导出的 PCM16 WAV、相同拍位窗口、FFmpeg LUFS 母带前的电平比较：

| 测量 | 第五版 | 第六版 |
| --- | ---: | ---: |
| 高潮后八小节相对前八小节 RMS 差 | +0.75 dB | +1.71 dB |
| 高潮后八小节相对桥段 RMS 差 | +4.23 dB | +6.84 dB |

这些数值描述能量与段落对比，不是感知响度、听感清晰度或兴奋程度的评分。完整对比在 release manifest 中记录，文件解码、格式、电平、源码 SHA-256 与检查状态同样以实际报告为准。

[第五版](../releases/ink-tide-v5/manifest.json)保留供对比。旋律和编曲为原创，本次没有重新核验参考曲或抖音热度，也没有使用参考录音。

最终 MP3 的 Integrated LUFS 均为 −14.00；true peak 实测为完整版 −1.50、hook −1.88、loop −1.91、高潮试听 −2.84 dBTP。四个文件都完成真实解码，帧数与源时长一致，无非有限值或满幅样本；完整曲单声道合并 RMS 变化约 −0.029 dB。

最终原电平完整曲 12 条分轨相加最大差约 `7.7650e−8`，差值 RMS 以 manifest 中实际结果为准。高潮后八小节分别测量每轨能量，并补充两次竖琴回应的电平；独立声部仍能相加还原 raw 混音，PCM16 量化误差与最终母带处理另计。

`npm run check` 的 50 项检查与构建通过；《墨潮》的浏览器目标检查及多轨播放器检查通过，覆盖采样重试、参数边界、同 seed、循环、独奏/静音、休止轨、缓存和当前选择导出。hook 同 seed 最大差约 `1.19209e−7`，差值 RMS 约 `7.90145e−9`；多轨浏览器相加最大差约 `5.24376e−8`，移除主奏比较最大差约 `5.75092e−8`，重复分轨与全静音结果为 0。最终两次竖琴的音量修订只涉及完整曲的高潮，随后重新渲染全曲三版和完整曲分轨，验证最终输出。

完整 `npm run test:browser` 未全部通过：旧曲《山河醒》的同 seed 最大差 `0.00010007619857788086`、RMS `4.058620125097906e−7`，超出原最大差阈值；一次独立复查仍失败。本次未改该曲音源或放宽 `< 1/65536` / `< 1e−6` 的阈值，旧版也已记录同类波动；这里不推断原因。《余温》《风起时》和《墨潮》各自的目标检查完成，首次失败与后续独立检查日志在本地 QA 目录保留，release manifest 如实标记整体回归失败。
