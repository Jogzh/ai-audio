# 《墨潮 / Ink Tide》第二版：箫与中国鼓

制作日期：2026-10-14。第二版回应用户“减少电子感，更喜欢箫和有变化的中国鼓”的反馈：速度从 124 BPM 调整为 **102 BPM**，箫成为领奏，中国鼓承担句子之间的推进与收束，琴声保留为稀疏应答。当前编曲只调度 `xiao`、`guqin`、`chineseDrum` 三类声部。所有声音由代码合成，没有使用外部乐器录音。

## 参考与判断依据

最初参考为用户指定的 [ZHENLOE《We Never》](https://music.163.com/song?id=3397959121)。第一版通过官方公开试听文件测量时长、节奏周期与段落频谱变化，详细方法、结果及局限保留在[第一版制作记录](ink-tide-production.md)。参考录音没有进入新曲混音，也没有用于复写旋律。

第二版的 102 BPM、箫长句、三种中国鼓体和鼓句安排来自用户后续偏好及本项目源码中的独立制作选择，不是对《We Never》乐器或演奏方式的识别结论。没有核验当日抖音热度，也没有进行人工耳听评审。源码可以说明“如何写、如何合成”；客观测量可以发现静音、电平、边界与重复渲染问题，不能证明旋律或音色已经好听。

## 旋律与配器

箫在第一拍进入，主旋律以 D 小调五声音阶构成。主题主要落在 C4–C5，桥段下探至 A3，最终段后八小节发展到 D5；较长的音值和句间空隙形成呼吸。琴声主要出现在箫的书面休止处，以低声部单音或少量双音作答。

箫音源分别生成谐波主体与气息噪声。较缓的起音、长音中的轻微气流起伏、起音后收敛的音高和延迟进入的颤音用于塑造吹奏感。琴音保留拨弦位置、力度层与轻微按弦变化。它们都是风格化合成音源，未声称达到实录乐器的真实度。

编曲没有继续调度第一版的电子主音、反拍低音、四分底鼓、沙锤、玉磬或持续 pad。箫、琴与鼓共用有限的短暗空间，音源不添加节奏回声或舞曲侧链起伏。这样的配器取舍旨在让箫句和鼓的音色变化更容易辨认，实际听感仍需试听。

## 中国鼓音源与鼓句

独立模块 `src/engine/chinese-drums.ts` 生成大、中、小三种鼓体的开放击、鼓边击与闷击。鼓膜部分使用圆形膜的非整数倍模态，叠加较弱的鼓腔共振与槌面接触声；每次开放击保留自身衰减，不按短音符时值硬切尾音。

| 变化 | 源码中的作用 |
| --- | --- |
| 三种鼓体 | 不同的基础音高、共振衰减与接触声频带 |
| 开放击、鼓边击、闷击 | 改变鼓膜与鼓腔占比、接触声及衰减长度 |
| 敲击位置 | 量化为靠中心、中间、靠边三档，改变各模态的激励强度；鼓边击使用独立的近边位置 |
| 力度 | 三个音色层改变频谱、起音和鼓皮瞬态，播放增益另行表达强弱 |
| 张力 | 三档张力改变共振频率；实际鼓谱包含低、中、高档 |
| 左右手与交替变化 | 轻微改变激励与音高，同一类鼓击交替两个可复现变体 |

实际鼓谱安排了跨位置档位的敲击，例如中鼓开放击会经过靠中心、中间和靠边的激励位置，变化会落入不同的合成档位。seed 只改变力度细节和音源触感；主要音高、鼓的起音位置、鼓体与击法顺序由乐谱写定。

鼓谱以四个不同的小节组成四小节句子，保留清楚的第一拍，在其余拍位用中鼓与小鼓接话。主段及最终段每八小节的句尾出现鼓花，最终段后半使用另一组鼓花；这些小节省去琴声应答，给箫长音之后的鼓击留出空间。轻段减少为每小节两击，桥段、引子与尾声没有鼓。

音源按需缓存有限长度的单声道 PCM，96 项 LRU 限制保留缓存大小；活跃声源继续持有正在播放的缓冲。渲染结束后释放节点、鼓缓存与交替状态，并恢复原来的 Tone 上下文。这些是工程上的资源管理约束。

## 结构与交付参数

40 小节、4/4 拍，结构为 **2 + 8 + 8 + 4 + 16 + 2**。第一拍出现箫声，约 **4.706 秒**进入主段；主体音乐约 94.118 秒。

| 段落 | 小节数 | 编曲作用 |
| --- | ---: | --- |
| 竹息 | 2 | 箫先陈述，少量琴声应答 |
| 鼓入墨潮 | 8 | 箫主题与完整鼓句进入，末小节鼓花 |
| 山间回声 | 8 | 箫力度回收，中国鼓减少为每小节两击 |
| 一息月白 | 4 | 无鼓桥段，低区长句与少量琴声 |
| 潮生 · 鼓语 | 16 | 主题回归，后八小节发展旋律并更换句尾鼓花 |
| 归山 | 2 | 箫与琴收束，保留空间尾音 |

导出参数为 **102 BPM / 移调 0 / seed 261014**。hook / loop 引用完整乐谱的实际第 3–10 小节，再独立离线渲染。

| 版本 | 内容 | 解码内容时长 | MP3 |
| --- | --- | ---: | --- |
| full | 40 小节 + 2.8 秒尾音 | 96.917642 s | [完整版](../releases/ink-tide-v2/ink-tide-full-102bpm-t0-s261014.mp3) |
| hook | 8 小节 + 1.4 秒尾音 | 20.223515 s | [精华片段](../releases/ink-tide-v2/ink-tide-hook-102bpm-t0-s261014.mp3) |
| loop | 8 小节，三轮预热后取第三轮 | 18.823537 s | [循环配乐](../releases/ink-tide-v2/ink-tide-loop-102bpm-t0-s261014.mp3) |

MP3 参数为 320 kbps / 44.1 kHz / 立体声，默认母带目标为 -14 LUFS / -1.5 dBTP / LRA 9。目标为项目制作选择，最终编码后的实测值以[第二版 manifest](../releases/ink-tide-v2/manifest.json)为准。原始 WAV 默认保留引擎 PCM16。MP3 是否无缝循环还取决于播放器是否正确处理编码延迟和填充信息。

```bash
npm run render -- --track ink-tide --seed 261014 --format both --out artifacts/audio/ink-tide-v2-local
npm run check
npm run test:browser
```

试听台 `/?track=ink-tide&version=hook` 使用第二版，seed 设为 261014。曲谱位于 `src/tracks/ink-tide.ts`，编曲位于 `src/music/arrangements/ink-tide.ts`，主音源位于 `src/engine/ink-tide.ts`，中国鼓合成位于 `src/engine/chinese-drums.ts`。

第一版 124 BPM 音频保留供比较：[full](../releases/ink-tide/ink-tide-full-124bpm-t0-s261014.mp3)、[hook](../releases/ink-tide/ink-tide-hook-124bpm-t0-s261014.mp3)、[loop](../releases/ink-tide/ink-tide-loop-124bpm-t0-s261014.mp3)。第一版的验证数值不作为第二版的测试结果。

## 验证记录与边界

最终源码的 **44 项测试及生产构建通过**。第二版专项浏览器检查通过，覆盖音源、低高 BPM 与移调、九种鼓体与击法组合、PCM 重复渲染、单声道、上下文恢复、播放器和 WAV 下载。最后一轮同 seed 最大采样差为 **4.4703484e-8**，差值 RMS 为 **3.01539e-10**，均低于项目保留的严格阈值。

三版最终 MP3 解码后的帧数与源 PCM 匹配，非有限采样和满刻度采样计数均为 **0**。编码后实测如下；时长与乐谱公式的微小差异来自整采样帧取整。
